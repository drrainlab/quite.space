## The ladder walked, and what each step taught

| configuration | 3 s | verdict |
|---|---|---|
| base, AGP debug (-O0) | minutes | AGP's debug variant compiles CMake at -O0; a debug APK must not mean debug inference → native build forced Release in every variant |
| base, -O3, NDK libomp | spin, no result | libomp deadlock-spins on this device (1712 s user CPU in a barrier, single-thread included) → GGML_OPENMP=OFF, ggml's own pthread pool |
| base, GGML_NATIVE=OFF only | 4.2 s | scalar kernels; the official whisper.android arch flags (armv8.2-a+dotprod+fp16) restore NEON |
| base + audio_ctx (floor 128) | 0.5 s / 21 s | the decoder loses itself below ctx 256 on very short clips |
| **base + audio_ctx ≥256 + max_tokens 96** | **0.82–0.89 s** | **pinned** |
| tiny-q5_1, same trims | 3.7–7.9 s + repetition loops | REJECTED: quality is the gate, not speed |
