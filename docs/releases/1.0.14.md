# 1.0.14 — the word leaves at once

**Sending no longer waits for reading.** A message used to leave inside
the node's one sync cycle, behind whatever that cycle was busy with — on
a phone following the catalog's public spaces, behind the fetch of every
one of them. Now the sender has its own lane: the moment you send, the
word goes to your recipients' relays, whatever else the node is doing.
A push that fails on the wire retries on its own clock, in seconds, not
on the next background tick.

**A failed background cycle retries in fifteen seconds**, doubling, never
later than the cadence it would have waited anyway — instead of the full
minute (three, under a parked listener).

**A dead socket costs four seconds, not ten.** After a Wi‑Fi change the
node's pooled connection to a relay can die in silence; the first write
into it now waits four seconds before the connection is replaced. Large
items keep the time their size needs.

**The desktop stays live while you read it.** Attention used to be the
window's focus alone, so clicking into an editor put your own node on
the background minute. Now the window being read on a second monitor —
polling every ten seconds — counts as attention, the same way the CLI's
`terminal ui` always has; a window hidden in the tray still lets the
node rest.

No relay change: everything here is on the node.
