# 1.1.2 — New default relay addresses

Quite Space now uses two regional relays by default:

- Europe: `r-eu.quite.space:7411`
- Russia: `r-ru.quite.space:7411`

Update the app to get the new addresses and their verified TLS key fingerprints.
The relay IDs stay the same for spaces that refer to these relays by their
official IDs. If you entered an old relay address manually, update it in your
relay settings.

The legacy Discover directory still uses its original catalog link. This
release updates the default messaging relays.
