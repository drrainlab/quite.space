# 1.0.15 — what a relay took shows as taken

**The dot was lying by omission.** A message to a peer whose relay this
node could only guess went to every official relay — and the sender's
screen kept saying "sending — still owed to a relay", because a copy
sent on a guess earned no receipt. The peer was reading it from that
very relay meanwhile. Now a relay that accepted the bytes is shown as
having accepted them, guess or not; a guess still counts as a guess for
everything else (the space stays held until a route is stated, the
history is re-offered when one arrives).

**A restart no longer forgets.** The relay's acceptance used to live in
memory only, so every update put the whole history back on the dot.
The high-water mark per space is now persisted with the node's own
state: what a relay took stays taken.

Behind the change: the recorded routes from the first weeks of the beta
were assumptions, and 1.0.12 started letting those age out after thirty
days — which is right, and which turned every peer who has not spoken
since into a guess. Peers on 1.0.12 and later state their relay when
they start, so the guesses resolve themselves as people update.

No relay change.
