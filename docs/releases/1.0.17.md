# 1.0.17 — a transfer in flight keeps the node awake

**The holder of a photo no longer sleeps between rounds.** A picture
crosses in rounds: the asking device asks, the holder answers up to
eight megabytes, the asker collects and asks for the rest. With the
holder's phone in a pocket each round used to be priced at the
background minute — three, under a parked doorbell that the system had
frozen. Now an answer that actually left for a relay keeps the holder's
heartbeat at ten seconds for two minutes, refreshed by every next
answer. Radio is spent only while somebody's picture is crossing; a
phone that answers nothing keeps the background minute.

**A photo's chunks no longer block the next message.** In a private
space the media answer used to land in the same mailbox as the frames —
one quota for both — so a picture in flight filled the box and the next
message to that device was refused, and the header said "relay · issue"
about a relay that was fine. Private spaces now carry the same per-space
reply box for media that public spaces have had since PH-1: the answer
goes to a box of its own, the frames mailbox stays free.

No relay change.
