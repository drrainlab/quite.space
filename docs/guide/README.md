## Пять понятий, на которых стоит всё

**Личность** — ваш ключ. Не логин и не аккаунт: её никто не выдаёт и никто
не может сбросить. Живёт на устройстве.

**Устройство** — то, чем вы входите. У одной личности их может быть
несколько, и каждое подписывает своё.

**Пространство** — место, где что-то происходит. Все виды мест в
quite.space — это одно и то же пространство с разными настройками, а не
разные сущности.

**Событие** — единица всего: сообщение, реакция, публикация, изменение
состава. Подписано автором, лежит в журнале пространства, не переписывается
задним числом.

**Узел** — программа, которая держит ваши данные и говорит с другими
узлами. Сервера, который «владеет» вашей перепиской, в этой схеме нет.

## Одно правило, которое объясняет интерфейс

**Человек выбирает действие. quite.space выбирает сеть.**

Нигде нет кнопок «отправить через реле», «отправить по LoRa», «синхронизировать
сейчас». Есть действие — написать, опубликовать, пригласить, — а каким
путём оно уйдёт, решает узел из того, что доступно. Поэтому же интерфейс
никогда не говорит «доставлено», если знает только «реле приняло»:
[TALK.md](TALK.md#что-значит-что-сообщение-ушло).
