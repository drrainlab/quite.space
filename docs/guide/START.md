# Начало: личность, устройство, резервная копия

Первое, что происходит при запуске, и единственное, что нельзя
восстановить ниоткуда.

---

## Что происходит при первом запуске

Приложение спрашивает **парольную фразу** и **имя**. Больше ничего: ни
почты, ни телефона, ни подтверждения. Регистрации нет — есть создание
ключа на этом устройстве.

    парольная фраза  →  шифрует хранилище на диске
    имя              →  то, как вас видят другие; меняется когда угодно
    личность         →  ключ; создаётся здесь и никуда не отправляется

**Парольная фраза не отправляется никуда и не проверяется сервером.** Она
расшифровывает данные на этом диске. Ошибётесь — данные не откроются, и
попросить сбросить не у кого.

После этого можно создать своё пространство или войти по ссылке —
[JOIN.md](JOIN.md).

---

## Личность и устройство — разные вещи

**Личность** — это вы. **Устройство** — то, чем вы сейчас пользуетесь.
У одной личности их может быть несколько.

Экран **«me»** (человечек в правом верхнем углу) показывает:

- **отпечаток** — короткая строка, по которой вас узнают;
- **проверочный код** — фраза, которую можно прочитать вслух, чтобы
  собеседник убедился, что говорит с тем самым устройством;
- **device id** (в «Technical details») — его дают владельцу пространства,
  чтобы он пригласил именно это устройство.

Смена имени — там же, кнопка **Change name**. Имя — заявление о себе, а не
проверенный факт; протокол его не удостоверяет, и интерфейс это не
изображает.

---

## Резервная копия — единственное, что нельзя вернуть иначе

Экран **«me»**, блок внизу.

Копия содержит **всё**: личность, пространства, ключи эпох, историю. Файлу
задаётся **своя** парольная фраза — она не обязана совпадать с той, что
открывает приложение.

```
me → passphrase for the backup file → Save a backup
```

Восстановление — намеренно отдельное действие и делается из командной
строки: работающий узел держит свою папку и не может восстановиться сам в
себя.

```bash
terminal restore --in FILE --data NEW-DIR
```

> **Потеряете все устройства и копию — личность не вернуть.** Никто не
> может её сбросить: в системе нет того, кто бы мог. Сделайте копию в
> первый же день.

---

## Где лежат данные

В папке данных узла (по умолчанию `~/.quiet-places`, задаётся флагом
`--data`). Папка заблокирована на один процесс: два узла на одной папке не
запустятся, и это правильно — иначе они перетёрли бы ключи друг друга.

Внутри — зашифрованное хранилище. Парольная фраза открывает его при старте.

---

## Экран «Protocol view»

Переключатель в шапке. Включает технический слой: идентификаторы событий,
подписи, состояния доставки — то, что обычно не нужно, но всегда доступно.

Это часть подхода: приложение не прячет, чем оно на самом деле занято. Если
что-то непонятно ведёт себя, protocol view обычно объясняет, что произошло.
