# Публикации

Вкладка **Posts** внутри пространства. Пост — это не длинное сообщение, а
документ: заголовок, блоки, обложка, комментарии, ревизии.

Атмосфера поста — звук и фон — вынесена отдельно:
[ATMOSPHERE.md](ATMOSPHERE.md).

---

## Создать пост

Кнопка **✍ New post**. Открывается композер.

Сверху — **тип поста**. Он не меняет механику, он говорит читателю, что
перед ним:

| тип | для чего |
|---|---|
| **article** | статья |
| **note** | заметка |
| **release** | релиз, выпуск |
| **log** | журнал, хроника |
| **space card** | карточка другого пространства — из таких собираются каталоги ([NAVIGATOR.md](NAVIGATOR.md#каталоги-и-discover)) |

Дальше: обложка, заголовок, короткое описание — и блоки.

---

## Блоки

Кнопки-чипы внизу композера добавляют блок в конец; у каждого блока есть
стрелки для перемещения и крестик.

| блок | что это |
|---|---|
| Text · Heading | текст и заголовок |
| 🖼 Image · ♫ Audio · 🎞 Video · 📄 File | медиа; файл загружается прямо в блок |
| ❝ Quote · Callout · Code · Link · Credits · — | цитата, выноска, код, ссылка, титры, разделитель |
| 📊 Poll · 📝 Form | интерактивные — читатель отвечает прямо в посте |
| 🎧 Listening room | совместное прослушивание внутри поста ([LISTENING.md](LISTENING.md)) |
| 🖼 Background | не блок, а **смена фона** в этом месте поста ([ATMOSPHERE.md](ATMOSPHERE.md)) |

Про последнюю строку стоит помнить: «Background» стоит среди блоков, потому
что означает **место** в посте, но на провод он уезжает не блоком, а частью
атмосферы. Для старого клиента это значит, что он просто не покажет
картинку, вместо того чтобы нарисовать посреди статьи непонятную карточку.

## Черновик, публикация, правка

- **Save draft** — черновик остаётся у вас. Он не уходит никуда.
- **Publish** — пост становится событием пространства: подписанным,
  видимым, с постоянным адресом.
- **Edit** на опубликованном посте — новая **ревизия**. Прежняя не
  исчезает, ссылка на пост не меняется, комментарии и резонансы остаются
  привязанными к посту, а не к его версии.

Если пост успели изменить где-то ещё, пока вы правили, публикация не
затрёт чужое молча — вам скажут, что пост изменился, а ваш черновик цел.

**Снять пост с публикации** можно — тогда у всех, включая тех, кому вы его
пересылали, он честно помечается «withdrawn by its author», а не исчезает
без объяснений. В веб-интерфейсе кнопки для этого пока нет; действие
доступно через API:

```
POST /api/spaces/{id}/publications/{doc}/archive
```

## ✨ AI-черновик

Строка внизу композера: опишите пост словами, нажмите **Draft** — и модель
заполнит заголовок, описание и блоки.

Два свойства, которые не меняются:

- **AI предлагает, публикуете вы.** Ни одна модель не пишет в журнал
  пространства сама.
- Куда уходит текст запроса, зависит от выбранного провайдера — см.
  [AI.md](AI.md).

## Как это выглядит у читателя

Лента постов — карточки: обложка, заголовок, описание, тип и число
комментариев. У поста с атмосферой на карточке будет неподвижный кадр и
две двери — «открыть тихо» и «открыть со звуком».

Внутри поста: статья, резонансы на самом посте и **комментарии**.
Комментарии — обычные события пространства, значит их видно тем же, кому
видно пространство.
